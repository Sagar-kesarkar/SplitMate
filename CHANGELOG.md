# Changelog

All notable changes to SplitMate are documented here.

## [Unreleased]

- Curated the native Android source for public collaboration.
- Added source-only CI, security guidance and architecture/build documentation.
- Removed obsolete web/backend scaffolding from the buildable source snapshot.

## [1.1.0-beta.1] - 2026-09-01

- Added persistent group lifecycle actions: mute, ownership-aware leave and recoverable delete.
- Added deterministic Demo group and personal expense records.
- Added reactive personal expense add/edit/delete behavior in Demo and Live modes.
- Added group budgets, balance details and signed balance reconciliation tests.
- Exported the existing internal-beta artifact later named `SplitMate-beta-V0.apk`.

The requested GitHub pre-release tag is `v0.1.0-beta.1`; the immutable APK manifest reports version `1.1.0-beta.1` (code 2).
